# Superstore Sales Analysis Dashboard

This project analyzes Superstore sales data using Microsoft Excel.

## Features
- Data Cleaning
- Duplicate Removal
- Pivot Tables
- Pivot Charts
- KPI Dashboard
- Business Insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Outcome
Created an interactive dashboard to analyze sales, profit, quantity, and shipping performance.
